QA Automation Assistant

AI chatbot for high-level QA automation guidance — test strategy, frameworks, CI/CD, Playwright, Cypress, and quality engineering best practices.

Run the live chatbot locally

GitHub Pages hosts this project page only. The chatbot needs a Node.js backend (Gemini API + SQLite), so run it on your machine: 

git clone <your-repo-url>
cd gemini-chatbot
npm install @google/genai
copy .env.example .env
npm run chatbot

Then open http://localhost:3000

Features

  • QA automation expert persona (high-level answers)
  • Google Gemini 2.5 Flash integration
  • Prompt history saved in SQLite
  • Alpine.js reactive chat UI
  • Automatic model fallback when API is busy
HTML CSS Alpine.js Node.js SQLite Gemini API

Get a Gemini API key

Create a free key at Google AI Studio and add it to .env as GEMINI_API_KEY.
